Connect after-booking → Google Sheets

One-time setup. After this, every client submit writes into your ops workbook automatically.

  1. Upload BFK-Ops-Workbook.xlsx to Google Drive → Open with Google Sheets.
  2. In that Sheet: Extensions → Apps Script.
  3. Delete any code in Code.gs, paste the script from Code.gs.txt, Save.
  4. Run setupBFKOpsSheets once (Approve permissions).
  5. Deploy → New deployment → Web app
    Execute as: Me
    Who has access: Anyone
    Deploy → copy the Web App URL.
  6. WhatsApp that URL to Chief of Staff / paste into site config — or edit after-booking/config.js on the site.
